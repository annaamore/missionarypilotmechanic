How AI Has Helped to Write This Newsletter

Because my dad is a software engineer, and I’m a broke college student, we had to find a way to create this website for free. I already had a domain name (if you want to know who my dad is: when choosing between two names for my little brother, my parents chose the name that had a domain available) so all that I had to do was create content and put it on the website!

The whole process starts with the post text which I write in a doc, then I give it to OpenCode and tell it to create a new post: the date, category, and the images that should go with it. I put the heic images in a folder that OpenCode then finds, converts, moves to a new folder, and inserts into the post. (Yay for skill building!) Once the post is created, I can review it locally and make edits before officially pushing it to the website. OpenCode talks to GitHub and through some magic puts the new post onto the website for the public to see.

While setting up the GitHub and domain permissions requires some technical expertise, once they are correctly set nothing else needs to be done to them. Skill building also requires previous experience, but it’s not actually necessary, just convenient. The biggest reason that this method is the best solution for me is that I can type something in plain English and OpenCode will update all the pages for me — I don’t need to know any coding at all!
